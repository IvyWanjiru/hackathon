    Website searches & stockouts

    Capture searches with zero results and explicit stockout requests. Pass an event ID so retries are counted once.

    Payload examples 
    POST /api/events/website-search
            {"query":"wireless earbuds",
            "results_count":0,
            "event_id":"search-123"}

            POST /api/events/stockout
            {"product":"Wireless Earbuds",
            "qty":2,"event_id":"stock-123"}

    Chatbots, quotes & other channels

    Use the signal API with the right channel and a stable external ID. Conversation history stays available as evidence.

    Signal API example 
    POST /api/signals
            {"text":"Need 2 wireless earbuds",
            "source":"chatbot",
            "external_id":"chat-123"}

    These are working receivers, not pre-connected vendor accounts.
